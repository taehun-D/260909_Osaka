# 오사카 쇼핑 — 오프라인 앱

## 폴더 구성

```
osaka-shopping/
├─ index.html      앱 본체 (건드릴 필요 없음)
├─ data.js         초기 목록 (선택 — 비워둬도 됨)
├─ sw.js           오프라인 캐시
├─ manifest.json / icon-180.png / icon-512.png
```

`img/` 폴더는 없어졌습니다. 사진은 폰에서 직접 넣습니다.

## 1. 올리고 홈 화면에 추가

아이폰은 파일 앱의 HTML을 홈 화면에 추가할 수 없어서 웹 주소가 필요합니다.

1. PC 크롬에서 app.netlify.com/drop 접속 (로그인 불필요)
2. `osaka-shopping` 폴더를 통째로 드래그
3. 나온 주소를 아이폰 Safari에서 열기
4. 화면 하단 오른쪽 **점 3개(...)** → 공유 → 홈 화면에 추가

iOS 26에서는 공유 버튼이 점 3개 안에 숨어 있습니다. 설정 > 앱 > Safari에서 '탭'을 '하단'으로 바꾸면 예전처럼 바로 보입니다.

## 2. 사진과 상품 넣기 — 전부 폰에서

하단 **상품 추가** 버튼을 누르면:

- **사진 찍기** — 카메라가 바로 열립니다. 매장에서 실물 찍어 넣을 때
- **앨범에서 선택** — 미리 모아둔 사진을 넣을 때

어느 쪽이든 가로 900px로 자동 축소되어 폰에 저장됩니다. 원본 용량은 신경 쓰지 않아도 됩니다.

입력란은 네 줄입니다.

- **일본어 정식명칭** — 점원에게 보여줄 이름
- **한글 발음** — 소리 내어 물어볼 때 쓰는 줄
- **제품 설명** — 층수, 종류, 수량 같은 메모
- **가격 / 우선순위**

매장은 설정 > 매장 추가, 또는 매장 헤더의 연필 아이콘으로 편집합니다.

## 3. 백업

**설정 > 백업 내보내기**를 누르면 사진까지 포함된 파일 하나가 공유 시트로 나옵니다. '파일에 저장'으로 iCloud Drive에 넣어두세요.

iOS는 저장 공간이 부족하면 앱 데이터를 지울 수 있습니다. 하루 한 번 정도 내보내두면 **백업 가져오기**로 그대로 복구됩니다.

## 4. 출발 전 확인

홈 화면 아이콘으로 실행해서 목록을 한 번 훑은 뒤, **비행기 모드를 켜고 다시 실행**하세요. 목록과 사진이 그대로 뜨면 준비 끝입니다.

## 5. data.js를 쓰려면 (선택)

PC에서 미리 목록을 채워두고 싶을 때만 씁니다. 앱을 **처음 실행할 때 한 번만** 읽어들이고, 그 뒤로는 폰 안의 데이터가 기준이 됩니다. 나중에 data.js를 고쳐도 자동 반영되지 않습니다 — 설정 > 초기 목록 다시 불러오기를 누르면 지금 데이터를 지우고 다시 읽습니다.

메모장으로 편집할 때 저장 인코딩이 UTF-8인지 확인하세요. 안 그러면 일본어가 깨집니다.

## 6. 앱을 다시 올릴 때

`sw.js` 첫 줄의 `osaka-v2`를 `osaka-v3`으로 올린 뒤 다시 배포하세요. 안 그러면 폰이 예전 캐시를 씁니다.

계정 없이 Netlify Drop에 올리면 다시 드래그할 때마다 새 주소가 생깁니다. 같은 주소에 덮어쓰려면 처음 배포 직후 나오는 'Sign up to claim this site'로 무료 계정을 만들어두세요.

## 알아둘 것

- 데이터는 폰 안에만 있습니다. 기기를 바꾸면 백업 파일로 옮겨야 합니다
- Safari 설정에서 '모든 쿠키 차단'이 켜져 있으면 저장이 안 됩니다
- 사진은 두 손가락으로 확대, 두 번 탭하면 확대/축소 토글
- 사진 오른쪽 위 동그라미가 구매 체크입니다. 사진 자체를 누르면 크게 열립니다
