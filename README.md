# 오사카 쇼핑 — 오프라인 앱

## 폴더 구성

```
osaka-shopping/
├─ index.html      앱 본체 (건드릴 필요 없음)
├─ data.js         초기 목록 — 분류 5개 / 27항목 (매장 개념 없음)
├─ img/            초기 목록 사진 18장 (첫 실행 때만 읽음)
├─ sw.js           오프라인 캐시 — 현재 osaka-v15
├─ manifest.json / icon-180.png / icon-512.png
├─ icon-source.svg  아이콘 원본 (고치고 싶을 때만)
```

`img/` 폴더는 **앱을 처음 실행할 때 한 번만** 읽힙니다. 사진은 그때 폰 안(IndexedDB)으로 복사되고, 그 뒤로는 폰 안의 사본이 기준입니다. 매장에서 찍은 사진은 지금처럼 앱에서 직접 넣으면 되고, `img/` 폴더를 나중에 고쳐도 자동 반영되지 않습니다.

## 1. 올리고 홈 화면에 추가

아이폰은 파일 앱의 HTML을 홈 화면에 추가할 수 없어서 웹 주소가 필요합니다. 지금은 GitHub Pages(`taehun-d.github.io/260909_Osaka/`)를 쓰고 있으므로, 이 폴더 내용을 그대로 커밋·푸시하면 됩니다.

1. 아이폰 Safari에서 주소 열기
2. 화면 하단 오른쪽 **점 3개(...)** → 공유 → 홈 화면에 추가

iOS 26에서는 공유 버튼이 점 3개 안에 숨어 있습니다. 설정 > 앱 > Safari에서 '탭'을 '하단'으로 바꾸면 예전처럼 바로 보입니다.

## 2. 사진과 상품 넣기

초기 목록 18장은 자동으로 들어갑니다. 나머지는 하단 **상품 추가** 버튼으로:

- **사진 찍기** — 카메라가 바로 열립니다. 매장에서 실물 찍어 넣을 때
- **앨범에서 선택** — 미리 모아둔 사진을 넣을 때

어느 쪽이든 가로 900px로 자동 축소되어 폰에 저장됩니다.

입력란은 네 줄입니다.

- **일본어 정식명칭** — 점원에게 보여줄 이름
- **한글 발음** — 소리 내어 물어볼 때 쓰는 줄
- **제품 설명** — 층수, 종류, 수량 같은 메모
- **제품군 분류 / 가격(엔) / 중요도**

엔화 가격을 넣으면 설정의 환율(100엔당 원)로 환산한 원화가 카드에 함께 뜹니다. 비워두면 `가격 미정`으로 표시됩니다.

**제품군 분류**가 홈 화면의 섹션이자 상단 칩입니다. 매장 개념은 없습니다. 상품이 하나라도 있는 분류만 칩으로 뜨고, 편집 화면의 **+ 새 분류 추가**로 얼마든지 늘릴 수 있습니다.

어디서 살지 적어두고 싶으면 **제품 설명**에 쓰면 됩니다 (예: `빅카메라 신사이바시점 · 5층`).

## 3. 백업

**설정 > 백업 내보내기**를 누르면 사진까지 포함된 파일 하나가 공유 시트로 나옵니다. '파일에 저장'으로 iCloud Drive에 넣어두세요.

iOS는 저장 공간이 부족하면 앱 데이터를 지울 수 있습니다. 하루 한 번 정도 내보내두면 **백업 가져오기**로 그대로 복구됩니다.

## 4. 출발 전 확인

홈 화면 아이콘으로 실행해서 목록을 한 번 훑은 뒤, **비행기 모드를 켜고 다시 실행**하세요. 목록과 사진이 그대로 뜨면 준비 끝입니다.

## 5. data.js를 고치려면

PC에서 미리 목록을 채워둘 때만 씁니다. 앱을 **처음 실행할 때 한 번만** 읽어들이므로, 고친 내용을 반영하려면 **설정 > 초기 목록 복원**을 눌러야 합니다. 이때 지금 데이터(직접 추가한 상품과 사진, 체크 표시)가 전부 지워지니 먼저 백업을 내보내세요.

항목에 `img: "파일명.jpg"`를 적고 같은 이름의 파일을 `img/` 폴더에 넣으면 사진까지 함께 들어갑니다. 사진 없이 `img`를 생략해도 됩니다.

메모장으로 편집할 때 저장 인코딩이 UTF-8인지 확인하세요. 안 그러면 일본어가 깨집니다.

## 6. 앱을 다시 올릴 때

`sw.js` 두 번째 줄의 `osaka-v15`에서 숫자를 하나 올린 뒤(`osaka-v16` …) 다시 배포하세요. 안 그러면 폰이 예전 캐시를 씁니다. `img/`에 사진을 추가했다면 `SEED_IMAGES` 목록에도 파일명을 넣어주세요.

## 알아둘 것

- 데이터는 폰 안에만 있습니다. 기기를 바꾸면 백업 파일로 옮겨야 합니다
- Safari 설정에서 '모든 쿠키 차단'이 켜져 있으면 저장이 안 됩니다
- 사진은 두 손가락으로 확대, 두 번 탭하면 확대/축소 토글
- 사진 오른쪽 위 동그라미가 구매 체크입니다. 사진 자체를 누르면 크게 열립니다
- 중요도는 빨강 **필수** / 남색 **있으면** / 회색 테두리 **눈에 띄면** 순입니다
- 면세 게이지와 매장 구분은 없앴습니다. 우측 상단 누적 금액과 분류 칩으로 봅니다
- 카드 사진은 5:4로 잘려 보입니다. 세로로 긴 폰 스크린샷을 그대로 넣으면 엉뚱한 부분만 보이니, 상품이 가운데 오도록 미리 잘라 넣으세요
- 아이콘을 바꾸려면 `icon-180.png`(180×180)와 `icon-512.png`(512×512)를 덮어쓰면 됩니다. 코드는 건드릴 필요 없고 `sw.js` 버전만 올리세요. 지금 아이콘의 원본은 `icon-source.svg`입니다
- 첫 실행은 인터넷이 연결된 상태에서 하세요. 사진을 그때 받아옵니다
